# Banking Transaction Processing System

## Project Overview

The Banking Transaction Processing System is a backend application developed using Java and Spring Boot to manage customers, bank accounts, and financial transactions.

The project uses MySQL for data storage and Spring Data JPA with Hibernate for database interaction. It focuses on maintaining data consistency and organizing banking operations efficiently.

## Tech Stack

Java, Spring Boot, Spring Data JPA, Hibernate, MySQL, Maven, Git and GitHub.

## Project Status

The project is currently under development. The database schema, Spring Boot setup, Java package structure and transaction enums have been completed. Entity classes are currently being developed.
