# Banking Transaction Processing System

## Project Overview

The Banking Transaction Processing System is a backend application developed using Java and Spring Boot. It is designed to manage banking operations such as customer management, account management, and financial transactions.

The project uses MySQL as its database and Spring Data JPA for database interaction.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Git and GitHub

## Database Design

The database includes the following tables:

- Customers
- Accounts
- Bank Transactions
- Transaction Audit
- Failed Transactions
